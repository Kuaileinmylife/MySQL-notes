
| 函数            | 说明                          | 示例                         |
| ------------- | --------------------------- | -------------------------- |
| ABS(X)        | 返回x的绝对值                     | SELECT ABS(-10);           |
| FLOOR(X)      | 返回不大于x的最大整数                 | SELECT FLOOR(1.3);         |
| CELT(X)       | 返回不小于x的最小整数                 | SELECT CELT(1.3);          |
| TRUNCATE(X,D) | 返回数组x保留到小数点后D位的值，截断时不进行四舍五入 | SELECT TRUNCATE(1.2328,3); |
| ROUND(X)      | 返回离x最近的整数，截断时要进行四舍五入        | SELECT ROUND(1.8);         |
| ROUND(X,D)    | 保留x小数点后D位的值，截断时要进行四舍五入      | SELECT ROUND(1.2323,3);    |
| RAND()        | 返回0~1的随机数                   | SELECT RAND();             |
| MOD(N,M)      | 返回N除以M以后的余数                 | SELECT MOD(9,2);           |
