
| 函数                       | 说明                                      | 示例                                                      |
| ------------------------ | --------------------------------------- | ------------------------------------------------------- |
| CAHR_LENGTH(str)         | 计算字符串个数                                 | SELECT CHAR_LENGTH('中国');                               |
| LENGTH(str)              | 返回值字符串str的长度，单位字节                       | SELECT LENGTH('中国');                                    |
| CONCAT(s1,s2,...)        | 将多个字符串拼接在一起，其中任意一个为NULL则返回值为NULL        | SELECT CONCAT('ad','main');                             |
| LOWER(str)<br>LCASE(str) | 将str中的字母全部转换成小写                         | SELECT LOWER('ABC');<br>SELECT LCASE('ABC');            |
| UPPER(str)<br>UCASE(str) | 将字符串中的字母全部转换成大写                         | SELECT UPPER('abc');<br>SELECT UCASE('abc');            |
| LEFT(s,n)<br>RIGHT(s,n)  | 前者返回字符串s从最左边开始的n个字符，后者返回字符串s从最右边开始的n个字符 | SELECT LEFT('abcdefg',5);<br>SELECT RIGHT('abcdefg',5); |
| LTRIM(s)<br>RTRIM(s)     | 前者返回字符串s，其左边所有空格被删除，后者返回字符串s，其右边所有空格被删除 | SELECT LTRIM(' abcde ');<br>SELECT RTRIM(‘ abcde ’);    |
| TRIM(s)                  | 返回字符串s删除了两边空格之后的字符串                     | SELECT TRIM(' abcde ');                                 |
| REPLACE(s,s1,s2)         | 返回一个字符串，用字符串s2替代字符串s中，所有的字符串s1          | SELECT REPLACE('abcde','ab','d');                       |
| SUBSTRING(s,n,len)       | 从字符串s中返回一个第n个字符开始，长度为len的字符串            | SELECT SUBTRING('abcdef',2,3);                          |
| CHAR_LENGTH(str)         | 计算字符串字符个数                               | SELECT CHAR_LENGTH('中国');                               |
| LENGTH(str)              | 返回值为字符串str的长度，单位为字节                     | SELECT LENGTH('中国');                                    |
示例：查询计科一个有多少人
```
SELECT COUNT* FROM stu WHERE LEFT(class,2)='计科';
```
示例：查询计科和软工各有多少人
```
SELECT LEFT(class,2),COUNT(*) FROM stu GROUP BY LEFT(class,2);
```
示例：查询名字有四个字的学生信息
```
SELECT * FROM stu WHERE CHAR_LENGTH(`name`)=4;
```
示例：查询学生成绩能被10整除的信息
```
SELECT * FROM score WHERE MOD(score,10)=0;
```
